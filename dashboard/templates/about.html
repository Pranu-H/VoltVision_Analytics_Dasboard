About VoltVision ⚡

Smart EV Analytics Platform designed to analyze, visualize, and predict Electric Vehicle growth trends across India.

📌 Project Overview

VoltVision is a data-driven Electric Vehicle Analytics Dashboard developed using Django, JavaScript, Chart.js, and Plotly.

The platform helps users explore EV trends, manufacturer performance, vehicle distribution, growth forecasting, and state-wise EV adoption using interactive visualizations.

It transforms raw EV datasets into meaningful insights for analysis and decision-making.

🎯 Objectives

  • Analyze EV growth trends
  • Visualize state-wise EV adoption
  • Compare manufacturer market share
  • Predict future EV growth
  • Provide downloadable reports
  • Build an interactive analytics platform

🚀 Key Features

📊 Interactive Charts

Dynamic visualizations using Chart.js and Plotly.

🌍 India Heatmap

State-wise EV adoption visualization across India.

📈 Forecast Analytics

EV growth prediction and YoY analysis.

🔍 Smart Filters

Advanced filtering by state, year, vehicle type, and manufacturer.

📥 Report Downloads

Export dashboard reports in PDF, Excel, and CSV formats.

⚡ Responsive UI

Modern responsive interface using Bootstrap 5.

💻 Technologies Used

Django Python JavaScript Chart.js Plotly Bootstrap 5 HTML5 CSS3 SQLite
